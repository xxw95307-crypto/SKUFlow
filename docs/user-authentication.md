# SKUFlow 登录与数据归属

线上使用 Sites 的 ChatGPT 身份认证。登录与退出必须通过顶层导航访问平台拥有的 `/signin-with-chatgpt` 与 `/signout-with-chatgpt`。应用不保存密码，不接受客户端提交的用户 ID，不实现伪造用户或生产环境匿名回退。

工作台按请求身份动态渲染。侧栏显示真实姓名（缺少姓名时显示邮箱）、邮箱与退出入口。`/login` 为登录或账号查看页面。

所有 API（包括附件、生成图片、视频文件、模型调用与发布）均经过 `withAuthentication`。无身份返回 401；无权访问返回 404；写操作校验同源。会话和任务创建时原子保存 `resource_owners`；列表按当前用户过滤；请求路径、查询参数及 JSON 中引用的任务和会话均检查归属。用户数据响应禁止缓存。

历史无主数据不会被任意用户认领。生产环境 `LEGACY_DATA_OWNER_EMAIL` 只配置为当前 Site 所有者的已验证邮箱；仅该真实登录身份可以执行一次历史数据归属迁移。未配置时旧记录保留但不会出现在任何用户列表。迁移不删除数据，也不改变 Shopify 店铺中的产品。

本地 `sites()` 开发插件提供明确标注的模拟登录；生产构建不包含该模拟身份。Shopify 测试店铺连接仍由服务器配置，未增加多商家 Shopify OAuth。
