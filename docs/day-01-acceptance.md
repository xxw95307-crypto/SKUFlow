# Day 1 验收记录

## 目标

打通“上传资料 → 创建任务 → 保存源文件 → 记录状态 → 启动解析”的最小真实链路，不在第一天伪装已经完成 AI 解析。

## 验收项

- [x] 页面可选择目标市场与目标平台。
- [x] 页面可接收图片、PDF、表格、Word、CSV 和文本文件。
- [x] API 对文件数量、单文件大小、总大小和扩展名做校验。
- [x] 源文件保存至 R2，文件元数据保存至 D1。
- [x] 任务创建后返回稳定任务 ID。
- [x] `CREATED → INGESTING` 由状态机验证并记录事件。
- [x] 非法跨级状态变更会被拒绝。
- [x] 任务状态、文件列表和事件历史可通过 API 查询。
- [x] 12 个平台进入统一平台注册表。
- [x] 平台凭据未写入源码。

## Day 2 输入

1. 为源文件增加解析任务队列接口。
2. 建立解析器 Tool Contract。
3. 将图片、PDF、Excel 和文本统一转换为带定位信息的 Evidence Chunk。
4. 为失败、重试和人工介入补充可观测日志。
